How it works

One endpoint is the whole API

Four steps from signing up to a PNG in your scenario. There is nothing else to learn.

  1. Create a free account and copy your API key from the dashboard.
  2. In Make or Zapier, add an HTTP → Make a request module set to POST.
  3. Point it at https://api.pixelpdf.dev/convert and add the header X-API-Key with your key.
  4. Attach your PDF as a file field using multipart/form-data, then run the scenario.
Request 
POST https://api.pixelpdf.dev/convert

X-API-Key:    your_api_key
Content-Type: multipart/form-data

file:         invoice.pdf
Response 
200 image/png        1 page
200 application/zip  2–5 pages

401 key missing or invalid
402 free credits used up
413 over the page or size limit
429 fair-use limit reached
OutputA single-page PDF returns one image/png. A multi-page PDF returns a .zip holding one PNG per page, in page order.
ResolutionEvery page renders at 200 DPI, so an A4 page arrives at roughly 1654 × 2339 pixels. There is no setting to get wrong.
